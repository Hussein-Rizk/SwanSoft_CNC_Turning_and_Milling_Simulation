## Reconstruction note

The `.nc` files in `GCode/` were reconstructed from the G-code printed in the PDF.
They are provided as readable GitHub documentation and should be verified against the
target CNC controller / SwanSoft machine configuration before execution on real hardware.

The report itself remains the source of truth if any formatting or interpretation differs.
